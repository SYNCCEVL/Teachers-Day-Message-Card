# 🎉 Teachers' Day Message Card for Sir Randy Bello

## 📖 Project Description

This project is a personalized Teachers' Day Message Card created using
HTML, CSS, and JavaScript to express appreciation and gratitude to
Sir Randy Bello.

The card features his picture, a heartfelt thank-you message, an
elegant design, and interactive animations to make the greeting
more special and memorable.

This project demonstrates the use of basic web development
technologies to create a creative and interactive digital greeting card.

## 🎯 Project Objectives

- To express gratitude and appreciation to teachers.
- To practice HTML, CSS, and JavaScript.
- To create an attractive and responsive digital greeting card.
- To apply animations and interactive features using JavaScript.
- To personalize a Teachers' Day message for Sir Randy Bello.

## 🛠️ Technologies Used

- HTML5 – Creates the structure and content of the message card.
- CSS3 – Designs the layout, colors, fonts, and animations.
- JavaScript – Adds interactivity, button effects, and sparkle animations.

## ✨ Features

- Personalized Teachers' Day greeting for Sir Randy Bello.
- Teacher's picture displayed on the message card.
- Elegant green, gold, and cream color combination.
- Heartfelt appreciation message.
- Interactive thank-you button.
- Floating sparkle animations.
- Responsive design for desktop and mobile devices.
- Simple and user-friendly interface.

## 🚀 How to Run the Project

1. Download or copy all the project files.
2. Place all files inside one folder named `TeachersDayCard`.
3. Make sure the teacher's picture is named `sir-randy-bello.jpg`.
4. Open the project folder.
5. Double-click `index.html` to open the card in your web browser.
6. Click the "Click for a Special Thank You" button to see the
   interactive effects.

No additional software installation is required to run the project.
